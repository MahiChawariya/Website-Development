# Money Multiplier Investment & Services
Money Multiplier Investment & Services is a web-based investment and financial services project developed using HTML, CSS, JavaScript, Python Flask, and SQL.

Technologies Used
HTML
CSS
JavaScript
Python
Flask
SQL

Features
User-friendly website interface
Investment services
Customer registration and login
Policy and service information
Customer enquiry and feedback
Database connectivity
Flask-based backend
SQL database management

Backend: Python Flask
